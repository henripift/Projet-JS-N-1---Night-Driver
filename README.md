A faithful recreation of the classic 1976 arcade game **Night Driver**, developed as a team project during our BTS SIO curriculum.

## 🎮 About The Project

Night Driver is a retro arcade racing game where players navigate a car through a winding road at night, avoiding obstacles and staying on track. Our mission was to recreate this classic gaming experience using modern web technologies.

### 🎯 Project Objectives

- Recreate the iconic **Night Driver** arcade game mechanics
- Implement game logic using **vanilla JavaScript**
- Master **HTML Canvas API** for rendering
- Practice **collaborative development** and **version control**
- Learn JavaScript fundamentals through hands-on experience

## 👥 Team

This project was developed by a team of **3 students** as part of our BTS SIO training program.

## 🛠️ Built With

- **JavaScript (Vanilla)** - Core game logic and functionality
- **HTML5 Canvas** - Game rendering and graphics
- **GitHub** - Version control and team collaboration

*Note: This project focuses on game logic using the HTML Canvas element rather than traditional HTML/CSS styling.*

## 💡 Key Features

- 🎮 Classic arcade gameplay mechanics
- 🌙 Night-time racing atmosphere
- 🚗 Smooth car controls and physics
- 🛣️ Dynamic road generation
- 📊 Score tracking system
